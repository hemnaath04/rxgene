# RxGene molecular artwork

These three assets were generated for this interface using the built-in image-generation tool on October 24, 2026, based on the RxGene design direction reviewed by Hemnaath. Exported to WebP with cwebp, preserving alpha on the isolated artwork.

- `molecular-background.webp`: pale-blue conceptual molecular atmosphere, with a quiet central reading area and ribbons around the edges.
- `dna-helix.webp`: transparent conceptual DNA helix with sea-glass blue backbone and green rungs; not a patient's actual sequence.
- `enzyme-gateway.webp`: transparent conceptual protein/enzyme channel for the qualitative explanatory particle path; not an exact CYP2D6 molecular reconstruction.

All labels, assessments, alerts, score values and pathway states are rendered by the interface from the real application data. No clinical text is baked into these images. The background is static; reduced-motion users retain a clear static explanation.
